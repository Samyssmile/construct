Notice the orange. The **datum** recurs across checked, selected, focused, and current states as a
line, ring, fill, or accent. This shared motif makes Construct legible and recognisable while its
tested color uses remain inside the WCAG&nbsp;2.2 contrast contract in light, dark, and
high-contrast themes. Open any component and use the **theme switcher** in the toolbar to inspect it.

## One idea, all the way down

Construct is built on a single conviction: **accessibility and identity are the
same job.** The orange datum reinforces interaction state across the system while making it
unmistakably itself — and the warm-concrete neutrals, the ink, and Lato are tuned to preserve the
tested contrast contract without giving up character.

Pick a component from the sidebar to see it in every theme, read its markup, and
run it through the live accessibility checks built into this Storybook.
